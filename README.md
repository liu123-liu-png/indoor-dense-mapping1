# indoor-dense-mapping

> 多模态视觉传感下的室内稠密三维重建与场景建图（手机相机方案）

## 项目简介
使用普通智能手机的相机与 IMU，在室内环绕拍摄视频，通过视觉惯性里程计（VIO）、
AI 单目深度估计与稠密融合，重建出可旋转、可量测的室内三维场景模型。无需激光雷达等额外硬件。

## 模块总览（19 个模块 M1–M19）
- 接入层 S0：M1 数据采集、M2 相机-IMU 标定、M3 时间同步、M4 数据预处理
- 前端层 S1：M5 VIO、M6 AI 单目深度估计、M7 关键帧选择
- 后端层 S2：M8 回环检测、M9 位姿图优化
- 重建层 S3：M10 深度融合、M11 TSDF 融合、M12 网格与纹理
- 语义层 S4：M13 语义分割、M14 语义融合、M15 实例标注
- 交互层 S5：M16 可视化、M17 导出、M18 质量评估、M19 远程合并
